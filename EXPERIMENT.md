# Focused authoring pilot

A template for evaluating one authoring session. Copy it into your own notes and fill it in to judge whether the agents got your project to development-ready, and where they caused friction.

**Goal:** With one human-guided Claude Code agent session, make a real project's Continuum ADL + relevant BDL + technology bindings + diagrams development-ready. Do not build the product.

## Run
Choose a real project and human-authored goal. Start `continuum-architect` in Claude Code; work naturally, intervening on consequential architectural decisions. Review generated models, scenarios, native diagrams and evidence. This is one subjective experiment, not a multi-arm benchmark.

## Assess
For ADL, BDL, bindings, scenarios, native diagrams and development package, record PASS / PARTIAL / BLOCKED / NOT CHECKED with the verification command/tool and remaining gaps. Green ADL compilation alone is not developer readiness.

## Agent interview
What helped? What was confusing? Where did you have to guess? Which tools or documentation were missing? What are your **top 3 highest-impact fixes**? Would you judge the handoff development-ready, and what evidence supports that?

## Human interview
How much friction did you experience? Were interruptions appropriate? Are the diagrams useful and accurate? Could a developer implement without making major architectural decisions? What one improvement would matter most?
